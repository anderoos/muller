# Purpose

-- MCP to Jira
-- MCP to CLI/ Slack

- Config: PM Style; waterfall, scrum, agile, kanban, lean
- OKRs/ Team goals (as source of truth).

# Commands and Skills
### Core
- Meeting Note Transcriber: transcribes text, extracts tasks, pushes to jira. Makes suggestions based on role, experience and performance.
- Standup relay : MCP to Slack or other tools, provides updates, asks for progress, communicates blockers and updates project based on response of user.
- Project init: Start a project, breaks down work and creates tickets
- Project termination: When all tickets are complete, schedules retrospective and closes out project.
- Summarizer - Gives a summary of the project, timeline and events in plain english.

### Supplementary
- Drift Detector: Flags tickets that haven't moved or scope changes. Ladders up to relay.
- Blocker tracker: Surfaces unresolved blockers before daily standup to avoid delays. Ladders up to relay.
- Sprint health check: Flags highest risk items/ dependencies. provides mid sprint analysis and recommendations.
- Decision logger. Ladders up to transcriber. Captures and assigns decisions from meetings, ownable, searachable and timestamped.
- Stakeholder briefer: Auto-generates monthly status summary emails for non technical audiences with links to Jira.
- Risk scanner: Identifies patterns of repeated slippage on the ticket/ person/ scope level. Repeated reassignment, ticketage, scope change rate.
- Project optimizer - re-planning, mid sprint pivots, scope cuts.
